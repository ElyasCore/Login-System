Login System

A simple Java console login system that checks a predefined username and password while limiting the user to three login attempts.

The project focuses on string comparison, loops, counters, conditional logic, and controlling program access based on user input.

Features
Enter a username and password
Compare the entered credentials with predefined values
Allow up to three login attempts
Display the number of remaining attempts
Show a successful login message when the credentials are correct
Lock the account after three failed attempts
Concepts Practiced

Scanner · String · equals() · for Loop · Counters · if/else · Logical Operators · Comparisons · break · Input Validation · Access Control Logic

Built as part of my Java learning journey to practice loops, counters, string comparison, and controlling program flow based on user input.
